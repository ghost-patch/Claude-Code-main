# Decisions

## 2026-09-18 — Repository as source of truth

GitHub will contain the scripts, configuration, skills and project knowledge required to reconstruct the workstation.

Kaggle sessions are considered disposable.

## 2026-09-18 — Desktop target

KDE Plasma X11 will be tested as the primary desktop environment.

XFCE remains a fallback if KDE Plasma does not provide reliable remote-desktop behavior.

## 2026-09-18 — Remote access

Three approaches will be evaluated:

- xrdp
- Cloudflare
- RustDesk

These will be tested separately rather than implemented simultaneously.
