# Project

## Purpose

Build a reproducible cloud workstation for development, Claude Code, frontend UI/UX, animation, MCP tooling and browser-based workflows.

## Primary environment

Kaggle is the initial disposable compute environment.

GitHub is the persistent source of truth.

## Planned technology areas

- Claude Code
- MCP
- Anime.js
- Motion / Framer Motion
- Remotion
- modern frontend UI systems
- cloud development
- browser automation
- remote desktop

## Current status

Foundation repository structure is being created.

Desktop and remote-access components have not yet been installed.
