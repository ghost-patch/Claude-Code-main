# Project: premium motion websites for clients
Goal: sell animation-heavy sites. Budget: $0. Free tools only for now.
Stack: Next.js, Tailwind, shadcn (Radix, Vega preset), Lenis + GSAP, Motion, R3F (3D tier only)
Rules:
- One background, one text effect, one signature scroll moment per page
- Never mix Anime.js with GSAP or Motion on the same element
- Respect prefers-reduced-motion; add a mobile fallback for 3D
- Install registry components with: npx shadcn@latest add @<registry>/<component>
- Run Playwright and fix console errors before calling a task done
Registries added: @kokonutui
